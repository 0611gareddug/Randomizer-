# 🎰 룰렛 러시 (Roulette Rush)

리스폰할 때마다 **주무기 · 근접 · 스킬 · 궁극기 · 도발** 5칸이 룰렛으로 무작위 결정되는 2D 픽셀 슬라임 난투 슈터입니다.
PC와 모바일 브라우저에서 모두 플레이할 수 있고, 그래픽과 사운드는 전부 코드로 생성합니다.

## 플레이
- **바로 플레이: https://0611gareddug.github.io/Randomizer-/** (GitHub Pages, 루트 `index.html` 또는 `docs/`)
- `dist/index.html` 파일 하나가 완성된 게임입니다. 정적 호스팅(GitHub Pages, Netlify 등)에 올리거나 로컬 서버로 열면 됩니다.
- 온라인 대전은 PeerJS 공개 중개 서버로 연결한 뒤 플레이어끼리 직접(WebRTC) 통신합니다. 봇전과 연습장은 인터넷 없이도 동작합니다.

## 주요 기능
- 장비 49종 (주무기 15, 근접 10, 스킬 10, 궁극기 8, 도발 6) · 등급 4단계 (일반/희귀/영웅/전설)
- 탑다운 난투 방식: 숨는 수풀, 적을 맞혀 채우는 궁극기 게이지, 머리 위 체력·탄약 표시
- 모드: 개인전, 팀전, 무기 연습장 · 맵 3종 (폐공장, 24시 편의점, 눈 덮인 마을)
- 보급품 낙하(전설 장비 확정) · 랜덤 맵 이벤트 6종 · 음식/젤리 회복
- 온라인 방 코드 대전(최대 8명, 빈자리는 봇) · 중간 합류 · 자유/빠른 채팅(욕설 필터)
- 봇 AI 난이도 3단계 · 킬피드 · 점수판 · 미니맵 · 결과 화면(시상대, MVP, 칭호)
- 닉네임/색상/표정/모자 커스터마이즈 · 전적 · 도감 저장
- 모바일: 고정 이동 스틱 + 공격/스킬/궁극기 조준 스틱(드래그 조준·탭 자동 조준), 전체화면 버튼, 버튼 크기 설정, 가로 화면 안내

## 개발
```bash
npm install
npm run build       # dist/index.html (난독화 + 개발자 도구 차단)
npm run build:dev   # .dev/index.html (디버그용, 커밋하지 않음)
```
- `src/sim.js` 게임 시뮬레이션(방장 권한) · `src/bot.js` 봇 AI · `src/game.js` 세션/동기화/연출
- `src/render.js` 렌더러 · `src/hud.js` HUD · `src/net.js` P2P · `src/main.js` 앱
- 로컬 다중 탭 테스트: `.dev/index.html?mocknet&lag=60` (같은 브라우저 탭끼리 모의 연결)
